# 渡劫行者

修仙題材的單機 Roguelite 割草遊戲，支援手機虛擬搖桿與電腦鍵盤操作。

## 目前內容

- 自動攻擊、妖潮、精英與首領
- 御劍、雷法、炎爆、心法、身法、護體六條技能路線
- 技能可由凡階升到靈階、玄階與天階
- 滿足指定功法階級後可融合成「萬劍雷劫」、「焚天破軍」或「太虛不滅」
- 回春丹、天雷符、聚靈幡、狂靈符等戰場道具
- 靈獸「青璃」會自動追敵、施放範圍星落，並在單局中覺醒與化龍
- 主角與靈獸具有移動、呼吸、轉身、施法與受擊動態
- 低干擾戰場模式：降低背景亮度、飽和度、漂移與地面紋理密度
- 主角與青璃使用分幀跑步、漂浮及施法動作
- 御劍與炎爆使用專用高辨識飛劍、熔岩火球素材，戰鬥和技能卡都能直接看清
- 暫停畫面可查看本局技能、等級與融合功法
- 每次選擇技能時可免費更換選項一次
- 原創 2.5D 修仙角色、三類妖物、首領與月夜古祠戰場美術
- 裝備掉落、特殊效果、裝備與批次分解
- 本機自動存檔

## 在電腦執行

需要 Node.js 22.13 或更新版本。

```bash
npm ci
npm run dev
```

完成後依終端顯示的網址，用瀏覽器開啟即可。方向鍵或 WASD 控制移動；手機使用左下方虛擬搖桿。

## 正式編譯

```bash
npm run build
```
