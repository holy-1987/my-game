# 渡劫行者

修仙題材的單機 Roguelite 割草遊戲，支援手機虛擬搖桿與電腦鍵盤操作。

## 目前內容

- 自動攻擊、妖潮、精英與首領
- 御劍、雷法、炎爆、心法、身法、護體六條技能路線
- 技能可由凡階升到靈階、玄階與天階
- 回春丹、天雷符、聚靈幡、狂靈符等戰場道具
- 裝備掉落、特殊效果、裝備與批次分解
- 本機自動存檔

## 在電腦執行

需要 Node.js 22.13 或更新版本。

```bash
npm ci
npm run dev
```

完成後依終端顯示的網址，用瀏覽器開啟即可。方向鍵或 WASD 控制移動；手機使用左下方虛擬搖桿。

## 正式編譯

```bash
npm run build
```
