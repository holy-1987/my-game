# 星華公主：魔法王國

一款原創公主主題的手機版三消遊戲，可直接在瀏覽器遊玩，不需要登入或建立帳號。

V1.2 新增滑鼠與觸控拖曳交換、全畫面自適應無滾輪版面，以及娜娜撲跳蓄力、揮爪與退場的連續施法動作。

V1.2.1 為娜娜新增專用抬爪姿勢，施法時會連續抬起與放下前爪，再接續星光爪擊。

V1.2.2 將娜娜施法演出放大約四成，延長進場、揮爪停留與退場時間，並延後棋盤消除時機以完整呈現動畫。

V1.2.3 將娜娜調整為 V1.2.2 的兩倍大，爪擊、光環、腳印與殘影同步放大，並再次延長完整施法演出。

## 遊戲特色

- 10×10 基礎棋盤搭配月光花窗、玫瑰拱門、王冠階梯、雙星迴廊等障礙造型
- 五種清楚標示的特殊圖案：皇家橫向火箭、皇家直向火箭、玫瑰炸彈、彩虹王冠與 2×2 星光飛碟
- 星光飛碟會以光束鎖定隨機寶石；皇家火箭會帶著尾焰、煙霧與光波沿整排慢速轟擊；玫瑰炸彈會先點燃引線再播放煙火與漸大的花瓣爆炸
- 特殊圖案啟動前，所有即將消除的寶石會先依火箭、炸彈、飛碟或同色魔法做出發光與浮動反應
- 任意兩個特殊圖案可互換並依序引爆，觸發三排火箭、雙重 5×5 爆破、全棋盤皇家極光等組合招式
- 達到三次連鎖會自動獎勵一步
- 一次消除九格以上會獲得公主祝福，隨機贈送特殊圖案
- 俄羅斯藍貓娜娜可在首頁互動，摸摸三次蓄力成功會變大撒嬌並讓下一關先獲得兩格蓄力；蓄力完成後會飛入棋盤施放大型三道星光抓擊
- 每日活動會輪替玫瑰星雨、月光寶藏與太陽慶典，左右會顯示符合活動名稱的圖案
- 每關都有「皇家挑戰」：引爆三個特殊圖案，過關時追加兩滴魔法露
- 四種不限次數的遊戲道具：實體魔杖會來回揮舞魔法弧、花雨會灑下大片玫瑰花瓣、洗牌會讓全部方塊飛散重排、加步會播放時光效果
- 王國設施會以原創華麗宮廷建築全景直接出現在首頁背景；拱門、噴泉、娜娜皇家莊園、星光御花園、皇家茶亭與晨曦大宮殿會隨修復及升級解除暗色、鍍金與皇家光暈
- 新增星冠祝福：完成三次九格以上的大消除後，保證在棋盤生成彩虹王冠
- 新增星願寶箱：累積四次額外連鎖後，自動獲得兩步與一枚特殊圖案
- 修正特殊圖案生成時顏色偶爾不一致、每日活動切換時間，並在棋盤沒有可移動組合時自動洗牌
- 首頁提供「重置測試進度」，可重新測試完整修復流程；存檔保存在目前瀏覽器的 localStorage
- 支援手機觸控與離線快取
