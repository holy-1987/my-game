# 星華公主：魔法王國

一款原創公主主題的手機版三消遊戲，可直接在瀏覽器遊玩，不需要登入或建立帳號。

## 遊戲特色

- 10×10 基礎棋盤搭配月光花窗、玫瑰拱門、王冠階梯、雙星迴廊等障礙造型
- 五種清楚標示的特殊圖案：皇家橫向火箭、皇家直向火箭、玫瑰炸彈、彩虹王冠與 2×2 星光飛碟
- 星光飛碟會飛向隨機寶石；火箭會沿整排轟擊；玫瑰炸彈會播放九宮格爆炸與花瓣效果
- 任意兩個特殊圖案可互換並依序引爆，觸發三排火箭、雙重 5×5 爆破、全棋盤皇家極光等組合招式
- 達到三次連鎖會自動獎勵一步
- 一次消除九格以上會獲得公主祝福，隨機贈送特殊圖案
- 白貓米露會在蓄力完成後飛入棋盤，以星光爪消除目標周圍 3×3 區域
- 每日活動會輪替玫瑰星雨、月光寶藏與太陽慶典，使用專屬星雨祭壇棋盤並提供加倍獎勵
- 四種不限次數的遊戲道具：魔杖、花雨、洗牌、加步，全部都有各自的動作效果
- 魔法露修復頁會直接顯示拱門、噴泉、小屋、花圃、茶亭與宮殿的實體設施狀態
- 支援手機觸控與離線快取
